# Satellite AI Flood & Urban Waterlogging Early Warning System (Global Edition)

An advanced early-warning system scaled for Bangladesh and worldwide monitoring. It integrates free Sentinel-1 Synthetic Aperture Radar (SAR) imagery via Google Earth Engine, Mapbox Satellite high-resolution imagery, a global intelligent smart search engine, and GeoPandas spatial risk assessment.

## Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Authenticate Google Earth Engine: `earthengine authenticate`
3. Run the dashboard: `streamlit run app/app.py`
